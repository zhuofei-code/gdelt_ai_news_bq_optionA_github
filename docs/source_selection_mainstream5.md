# Mainstream-Only Source Design

This version removes all specialist outlets and keeps only `5` mainstream,
general-interest outlets per country.

## Selection Rule

For each country, the source list is the `mainstream_domains` subset already
documented in `Option A`. No specialist domains are retained in this design.
